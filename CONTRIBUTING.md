# Commit Message Strategie

## Formaat

```
<type>(<scope>): <beschrijving>
```

## Types

| Type      | Wanneer                                              |
|-----------|------------------------------------------------------|
| `content` | Tekst, afbeeldingen, sponsors, evenementen aanpassen |
| `feat`    | Nieuwe functionaliteit of pagina                     |
| `fix`     | Bug of fout herstellen                               |
| `style`   | Visuele aanpassingen (CSS, layout)                   |
| `chore`   | Onderhoud, dependencies, config                      |

## Scopes

`home`, `events`, `sponsors`, `kalender`, `over-ons`, `nav`, `global`

## Voorbeelden

```
content(home): nieuwe sponsor toegevoegd — Spar Middelkerke
content(events): ponytornooi 2026 datum bijgewerkt
content(sponsors): logo helaco vervangen
feat(kalender): activiteiten sectie toegevoegd
fix(home): typo in clubbeschrijving
style(nav): lettertype aangepast
```

## WhatsApp-updates

Wanneer aanpassingen gevraagd zijn via WhatsApp, voeg je optioneel toe:

```
content(sponsors): logo JD Engineering bijgewerkt (via WhatsApp)
```
